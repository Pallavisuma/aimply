⚙️ Setup & keys

1 · Get free API keys

JSearch: RapidAPI → Subscribe Basic ($0) → My Apps → Security → copy Application Key = JSEARCH_API_KEY.

Adzuna: developer.adzuna.com → create app → ADZUNA_APP_ID, ADZUNA_APP_KEY.

Gemini (for tailoring/PDF import): aistudio.google.com/apikey = GEMINI_API_KEY.

2 · Save in .env

JSEARCH_API_KEY=...
ADZUNA_APP_ID=...
ADZUNA_APP_KEY=...
GEMINI_API_KEY=...

3 · Pre-fill needs a browser once

npx playwright install chromium
